External delivery setup

Provider settings, fallback fees, map zone and parcel defaults

This page does not select the delivery mode or payment methods. Use Delivery Mode Settings for that. This page only prepares external providers such as Shiprocket, manual courier, Rapido/Ola/Uber-style hyperlocal delivery, and manual fallback charges.

1. Provider connection settings

Keep API switches OFF until credentials and webhook tokens are available. Manual booking remains available separately.

2. Fallback delivery charge rules

These fees are used when a live courier/hyperlocal quote is not connected or fails. Product price and platform fee remain separate.

Checkout fees
  • External Local fee = base fee + distance × per-km fee, then minimum fee is applied.
  • Third-party Shipping can be kept as fixed courier charge by setting per-km fee to 0.
  • Checkout also keeps the old in-house fee as a safe fallback reference to avoid accidental undercharging.

3. Pickup map and optional external service zone

Use the map to save a default pickup point and draw an optional external delivery boundary. The zone is applied only when the checkbox is enabled.

Map zone

  • Draw Zone: click at least 3 points to create a boundary.
  • If zone enforcement is OFF, checkout continues using existing store/serviceability rules.
