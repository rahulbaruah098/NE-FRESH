Simple Delivery Operation

Use either In-house Delivery or Connected External Delivery.

In-house delivery is your own full delivery-boy system, so it runs alone. When Admin selects Connected External Delivery, in-house is disabled and checkout routes orders between External Local and Shiprocket based on distance/zone.

1. Choose delivery operation

Choose one operation style. In-house is standalone. External Local and Shiprocket can work together only under Connected External Delivery.

2. External delivery channels

These switches apply only when Connected External Delivery is selected. Keep both ON for the normal external flow.

3. Customer payment methods

Backend keeps the old COD value for compatibility, but customers see Pay Online on Delivery. Shiprocket orders are always forced to Online Payment before shipment creation.

4. Return / Refund

This switch controls customer return request, store returns, and admin refund/return pages.

Final flow:
  • In-house Delivery Only: external delivery channels stay OFF and your current delivery-boy workflow stays unchanged.
  • Connected External Delivery: in-house delivery stays OFF. External Local handles local partner deliveries with hard-coded fare and order ID reference only.
  • Shiprocket: outside-local/inter-city orders use Shiprocket/Courier shipping with Online Payment only. Product-wise package dimensions are used where available.
