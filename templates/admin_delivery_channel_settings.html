Channel Settings

External local is simple. Shiprocket is real API-ready.

External local delivery does not create Rapido/Ola/Uber booking records. Checkout only charges an assumed local fare and the customer receives the NE FRESH order reference. Shiprocket settings are used for courier shipping orders when Store marks the package ready.

Enable/disable the channels from Delivery Operation Settings. This page only stores fare, zone, package and Shiprocket credential settings.

1. External local fare rules

Used for Rapido-style local delivery without API integration. Fee = base fee + distance × per-km fee, with minimum fee applied.

  • No rider payment, Rapido fare settlement, or external local booking status is tracked in NE FRESH.
  • The delivery charge collected from customer is your assumed local delivery charge.
  • For Pay Online on Delivery, customer pays Store/NE FRESH by UPI/online at handover, not the external rider in cash.

2. External local pickup and zone map

Draw the local external delivery zone if you want checkout to restrict external local delivery to a map boundary. If disabled, distance limit controls local eligibility.
