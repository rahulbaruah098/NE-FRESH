# NE FRESH Menu + Tracking Transparency Update

Updated only UI/navigation wording and tracking guidance around the current delivery/payment flow.

## Admin menu changes
- Added public Home button under Main.
- Renamed Dashboard to Admin Dashboard.
- Grouped delivery links into:
  - Delivery Routing & Channel Availability
  - In-house delivery-boy system
  - External Local Fare & Shiprocket Setup
  - Shiprocket / Courier Orders
- Grouped money-related pages under Finance & Settlements.
- Renamed unclear settlement labels so Admin can understand what each page controls.

## Store menu changes
- Renamed Store order buttons to make roles clear:
  - All Customer Orders
  - In-house Delivery Assignment
  - Shiprocket / Courier Orders
  - Store Payout Status
- Added clearer reporting labels under Store Payments & Reports.

## Customer transparency changes
- Checkout now explains how tracking differs by delivery route.
- Track Order page now explains:
  - In-house delivery: delivery-boy tracking appears after assignment.
  - External local delivery: no Rapido/Ola/Uber record is stored; use NE FRESH order ID/reference for support.
  - Shiprocket/courier: AWB/tracking link appears after shipment booking.

## Logic preservation
No delivery fee formula, platform fee formula, order placement logic, store payout logic, delivery-boy assignment logic, Shiprocket booking logic, or refund backend logic was intentionally changed.
